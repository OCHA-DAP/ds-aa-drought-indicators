# Pages site

**Live:** https://ocha-dap.github.io/ds-aa-drought-indicators/

Generated by `scripts/make_site.py` from `results/results.json` and `tables/` (see the repo README
for the pipeline). `pages/index.html` is the landing page with the cross-country summary; each
`pages/<iso3>/index.html` is one country. The prose blocks on the landing page live in
`pages/_landing_intro.html` and `pages/_landing_outro.html` (hand-written, injected by the
generator; files starting with `_` are not deployed). Regenerate and commit; push to `main`
deploys.
